# Community Standards

TaskStateGuard welcomes technically rigorous, respectful participation.

- Discuss ideas and evidence, not personal characteristics.
- Assume good intent while remaining precise about security and correctness.
- Do not post credentials, personal data, task records, private paths, or
  unredacted production output.
- Do not harass, threaten, impersonate, or publish another person's private
  information.
- Respect maintainers' decisions about scope, safety, and release timing.

Repository maintainers may edit, hide, or remove content and may restrict
participation when these standards are violated. Use GitHub's reporting tools
for abusive conduct. If a report itself contains sensitive security details,
use the private vulnerability-reporting path in [SECURITY.md](SECURITY.md).
